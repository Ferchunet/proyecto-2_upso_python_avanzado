## Parte 1

El programa está en `fotoapp.py`. El cuaderno `fotoapp_testdev.ipynb` solo importa esas funciones y las prueba, no las vuelve a escribir.

Para abrir el menú:

```
python fotoapp.py
```

La opción 1 va primero: abre la foto y la redimensiona para Youtube, Instagram, Twitter o Facebook. Después se puede ajustar el contraste, aplicar un filtro o ver los bordes.

Usamos una foto distinta en cada punto:

- Punto 1: baires.jpg
- Punto 2: oscura.jpg (oscura) e img2.jpg (mucha luz)
- Punto 3: madryn.jpg, con los 9 filtros
- Punto 4: MarieCurie.jpeg, con Canny y Laplaciano

Las fotos nuevas quedan en la carpeta `fotos_mejoradas`.
